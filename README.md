# Statsinator
pwhl stats analysis

I'm working from Scott Powers' course materials on sports analytics trying to get more in depth analysis of the 2025/26 PWHL season. This is mostly for fun. 
Data from sportsdataverse.

## done: 
- unpacking and organizing schedule data
- expected win % by score differential, compared to actual win %, and tuning
- rasch model
- input validation, testing, stability things


## now working: 
- regularized adjusted plus minus, per team
- power play stats (see pp.py for details)
